# Search Strategies

Search like a researcher, not a guesser: form a hypothesis about where the answer lives,
query deliberately, and adapt based on what comes back. Most failed searches aren't a
tool problem — they're a query problem.

## When to use

Use this skill when looking something up across files, a knowledge base, the web, or any
searchable system — especially when the first obvious query comes back empty, noisy, or
overwhelming. Reach for it before declaring "I couldn't find it".

## How to search

1. **Define what "found" looks like first.** Name the specific thing you need and what a
   good-enough answer is. A fuzzy target produces a fuzzy search and no clear stopping point.
2. **Start with the most distinctive terms.** Lead with the rare, specific words most
   likely to appear in the answer — an exact error string, a proper name, a unique phrase.
   Generic words match everything and surface nothing.
3. **Iterate deliberately — broaden or narrow.** Read the first results, then adjust on purpose:
   - Too few hits: broaden — drop terms, swap in synonyms and alternate phrasings, relax filters.
   - Too many: narrow — add specific terms, quote exact phrases, filter by date, type, or source.
   - Wrong results: you have a vocabulary mismatch — find the term the source actually uses
     (often visible in a near-miss result) and re-query with it.
4. **Try more than one angle before giving up.** If a term fails, attack from a different
   one — a related concept, the opposite, an example, a place it might be referenced. Two
   or three distinct framings beat ten reruns of the same wording.
5. **Evaluate source quality as you read.** Prefer primary and authoritative sources over
   hearsay; check how current it is and whether it actually answers your question. Corroborate
   anything load-bearing with a second independent source.
6. **Know when to stop.** Stop when you can answer the question and a second source agrees,
   or when fresh queries stop turning up anything new. Don't over-search a settled answer;
   don't declare defeat after one wording.

## Quality bar

A good search ends with a defensible answer, the source it came from, and a clear note of
anything still uncertain. If you stopped early, say what you'd try next; if you couldn't
find it, report which angles you tried so the gap is real, not just unexplored.
