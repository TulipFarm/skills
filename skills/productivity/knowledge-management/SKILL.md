# Knowledge Management

Run the knowledge base as a living reference the whole business trusts, not a dumping
ground. A knowledge base is only as good as its worst stale page — the moment people
stop believing it's current, they stop using it and rebuild knowledge in their heads.

## When to use

Use this skill when setting up a knowledge base, when it has sprawled into something
nobody can navigate, or when deciding where a piece of information belongs and how long
it should live. Reach for it when the same question keeps getting asked because the
answer isn't findable.

## How to organize

1. **Structure around how people look, not how it was created.** Group into a shallow
   set of collections that match the questions people actually ask (how we do X, who
   owns Y, policy on Z). Two levels of nesting is usually enough; deep hierarchies hide things.
2. **Set a clear bar for what's worth capturing.** Capture the durable and reusable:
   decisions and their rationale, repeatable processes, policies, answers to recurring
   questions. Don't capture transient chatter, one-off threads, or anything that ages out in days.
3. **One source of truth per topic.** Before adding a doc, search for an existing one and
   extend it instead of forking a near-duplicate. Competing versions of the same answer
   are how a knowledge base loses trust.
4. **Make each document findable on its own.** A clear title that matches how people
   search, a one-line summary up top, and useful tags or links. If it can't be found, it
   doesn't exist.
5. **Assign an owner and a freshness signal.** Every important doc has someone responsible
   and a last-reviewed date. Ownerless docs rot silently.
6. **Retire stale content deliberately.** Review on a cadence: update what's drifted,
   merge duplicates, and archive what's no longer true. Mark superseded docs clearly and
   point to the current one — a wrong page left standing is worse than a missing one.

## Quality bar

The knowledge base is healthy when a newcomer can find the right answer by searching the
obvious term, when each topic has exactly one current home, and when nothing on the front
pages is known to be wrong. Findable, deduped, and current — in that order. If it's a
sprawl of stale duplicates, prune aggressively before adding anything new.
