# Team Messaging

Write team-chat messages that get read and acted on, not skimmed and forgotten. In a
busy channel, attention is scarce — front-load the point and make the ask impossible to miss.

## When to use

Use this skill when drafting a team-chat message, an announcement, or a request that
needs a response — especially anything going to a group, where a wall of text dies
unread. For longer narrative updates use the relevant report skill; this is for chat.

## How to write

1. **Lead with the point or the ask.** First line says what this is and what you need:
   the decision, the request, the headline. Don't bury it under a paragraph of windup —
   the reader should know in one line whether and how to act.
2. **State context only as much as needed.** Give the minimum background to make the ask
   make sense, then stop. Link to the detail instead of pasting it.
3. **Format for skim.** Short paragraphs, blank lines between ideas, bullets for lists,
   bold on the few words that carry the message. A solid block of text reads as "later"
   and never gets read.
4. **Make urgency and the deadline explicit.** Say whether this is FYI or needs action,
   and by when. "When you get a chance" and "before 3pm today" are different messages —
   don't make the reader guess.
5. **Make the next step unmistakable.** End with exactly what you want to happen and from
   whom: react to confirm, reply with X, no action needed. Name people directly when the
   ask is theirs; a question to "everyone" is a question to no one.
6. **Match tone to the room and keep it tight.** Professional and warm, no filler. Read it
   once as the recipient — if the ask isn't obvious in five seconds, rewrite the first line.

## Output format

```
<One line: the point or the ask.>

<Minimal context — a sentence or two, with a link to detail.>

<Bullets if there are parts:>
- <point>
- <point>

<Explicit next step + deadline: who does what, by when.>
```

For an announcement, open with a one-line headline so people grasp it from the preview.
Keep messages short enough to read without scrolling — if it's longer, it's a document
with a one-line summary, not a chat message.
