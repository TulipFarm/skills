# Weekly Review Checklist

A short, repeatable pass that keeps the task system trusted. Run it once a week, same
slot, ~20–30 minutes. Work top to bottom; don't start new work mid-review.

## Get clear

- [ ] **Empty the inboxes.** Sweep chat, email, notes, voicemail, and your own head into
      the task inbox. Capture only — don't act yet.
- [ ] **Process the inbox to zero.** For each item: do it (under two minutes), turn it
      into a next action, file it to a project, defer it to someday/later, or drop it.

## Get current

- [ ] **Review active projects.** Confirm every project has exactly one live, concrete
      next action. Add one where it's missing.
- [ ] **Review next actions.** Delete what's done, rewrite what's gone vague, re-prioritize
      what's changed.
- [ ] **Check due dates and the calendar.** Look at the week ahead and the week behind.
      Surface anything due soon; reschedule anything slipped.
- [ ] **Review waiting-on items.** Anything you're blocked on — follow up or note the
      next nudge date.

## Get ahead

- [ ] **Scan someday/later.** Pull anything now ripe into the active list; drop what no
      longer matters.
- [ ] **Pick the week's priorities.** Choose the few outcomes that would make the week a
      win, and make sure their next actions are at the top.

End state: inbox at zero, every project with a next action, the week's top priorities
obvious. If you skip everything else, still process the inbox and confirm next actions —
that's the part that keeps the list trusted.
