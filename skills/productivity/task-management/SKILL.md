# Task Management

Run a task system that holds everything so the person doesn't have to. The goal is a
trusted list, not a tidy one — if it isn't trusted, it gets bypassed and rebuilt in
someone's head.

## When to use

Use this skill when asked to organize a backlog, plan a day or week, capture a pile of
loose to-dos, or set up a way to track work. Reach for it whenever commitments live in
scattered messages, inboxes, and memory rather than one place.

## How to organize

1. **Capture everything to one inbox first.** Sweep every open commitment out of chat,
   email, notes, and memory into a single list. Don't organize while capturing — get it
   all down, then sort. A second home for tasks guarantees both get ignored.
2. **Turn each item into a concrete next action.** "Website" is a project, not a task.
   Rewrite it as the next physical, visible step: "draft three homepage headlines".
   - If an item needs more than one step, mark it a project and name only its next action.
   - If it takes under two minutes, it's faster to just do it than to track it.
3. **Assign a priority and a real due date.** Separate genuinely time-bound (a hard
   deadline) from merely urgent-feeling. Most things are neither — protect that signal.
   - Use a small scale (high / medium / low), not ten levels nobody honors.
   - A due date is a commitment, not a wish; don't date things that aren't actually due.
4. **Group by project and by context.** Cluster tasks under the project they serve, and
   tag by where they get done (calls, errands, deep work) so a work session has a ready list.
5. **Defer what isn't now.** Anything not actionable this week goes to a someday/later
   list or a tickler with a surface-by date — out of the active list, not lost.
6. **Review on a cadence.** A daily glance to pick the day's few; a weekly review to
   process the inbox to zero, update statuses, and check that every project has a live
   next action. The weekly review is what keeps the system trusted — see
   `references/weekly-review.md`.

## Quality bar

The list is working when the person can stop trying to remember things, when every
active item names a next action they could start right now, and when the day's top
priorities are obvious without re-deciding. If it's a graveyard of stale, vague items,
it has stopped being trusted — prune hard and rebuild the next-action habit.
