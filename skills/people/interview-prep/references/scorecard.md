# Interview Scorecard Template

Copy this per role. Set competencies from the role's must-have criteria, write the 1–4
anchors before interviewing, and have each interviewer fill it independently before the
debrief. This is hiring guidance, not HR or legal advice.

## Header

```
Role: <title>            Level: <L>
Candidate: <name>        Date: <date>
Interviewer: <name>      Competency owned: <area>
```

## Rating scale

| Score | Meaning |
|-------|---------|
| 1 | Well below bar — clear gap, no supporting evidence |
| 2 | Below bar — partial signal, notable concerns |
| 3 | Meets bar — solid evidence the role needs |
| 4 | Above bar — strong, repeatable evidence |

## Competency grid

Write the "looks like" anchor for 1 and 4 per competency before the loop, so ratings
mean the same thing across interviewers.

## Decision

```
Per-competency ratings recorded above (independent, pre-debrief).
Overall: Strong hire / Hire / No hire / Strong no hire
One-line rationale tied to evidence: …
```

Rules: rate every competency against its anchors, not against other candidates. Record
evidence for each score — a rating with no example does not count. Submit before the
debrief; do not adjust to match the room.
